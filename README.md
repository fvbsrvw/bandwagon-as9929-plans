## AS9929 是什么线路，为什么联通用户在意它

AS9929 是中国联通的精品骨干网，官方体系里叫 China Unicom Premium（CUP），和大众熟知的普通联通 169 网（AS4837）不是一回事。用个直白的类比：AS4837 是联通的“国道”，晚高峰会堵；AS9929 是专门为高质量国际业务修的“快速路”，路由质量、拥塞控制和延迟稳定性都明显更好，境外侧则由联通国际（AS10099）承接。

对联通宽带用户来说，这条线路的价值很实际：晚高峰访问海外服务器不容易丢包，延迟曲线平稳，不像普通线路那样一到晚上就抽风。这也是为什么市面上接入 AS9929 的 VPS 一直有人抢。

搬瓦工（BandwagonHost）是国内用户最熟悉的老牌 VPS 商家之一，旗下机房从 2021 年起陆续接入了联通 AS9929 线路，是目前提供联通优化线路选择最多的商家之一。问题在于，它家页面全英文、套餐命名混乱，AS9929 藏在机房代码后面，新手很难自己找出来。
